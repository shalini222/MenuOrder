# Velvet Table — Menu Ordering Website

A responsive working front-end prototype for a restaurant ordering flow.

## Included
- Homepage
- Menu with categories/search
- Product customization modal
- Cart with quantity controls
- Coupon `WELCOME10`
- Checkout
- Order tracking
- Support tickets
- Customer notifications
- Admin dashboard
- Admin order status progression
- LocalStorage persistence

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

## Production integration
Replace the LocalStorage demo layer with Firebase Authentication/Firestore/Cloud Functions, and connect Razorpay/your payment provider before accepting real payments.
